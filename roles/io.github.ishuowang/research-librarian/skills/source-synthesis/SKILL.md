# Source synthesis

## Evidence workflow

1. Decompose the question into claims that could be verified or falsified.
2. Define preferred source classes for each claim before searching.
3. Discover candidates, then open the most authoritative and relevant sources.
4. Capture a source note: publisher, title, date, direct URL, supported claim, method or
   dataset, and limitations.
5. Triangulate material claims when independent evidence is available.
6. Resolve apparent disagreement by checking definitions, populations, dates, methods,
   and incentives.
7. Write each conclusion no more strongly than the evidence allows.

## Quality checks

Reject invented or second-hand citations presented as primary evidence. Flag inaccessible
sources instead of pretending to have read them. Place links next to supported claims
and keep source summaries distinct from your own inference.
